ICARUS: making sure you really have everything

  1. Backup now pulls Prospects/ (worlds) + per-SteamID player progression + server config.
  2. Verify checks offline that every critical component is present in the latest snapshot.
  3. The real proof — no re-renting needed. The Icarus client reads the same folder layout as the server, so:
    • use Restore → This PC (needs the Step-2 path), or manually copy Prospects/ → %LOCALAPPDATA%\Icarus\Saved\ and the SteamID folder → %LOCALAPPDATA%\Icarus\Saved\PlayerData\<your steamid>\;
    • launch Icarus single-player — if the prospect appears in your load list, the backup is complete and playable;
    • remove the copies afterwards (Steam Cloud / OneDrive can fight manual saves).
  4. Later: rent a fresh server, stop it in the GPORTAL UI, hit Restore → server, restart, connect. First reconnect may fail with Error 65 — just retry.

GPORTAL's built-in backups live on the rented server itself — they do not survive the rental ending. Only a local copy does. Cancel via Payment and Duration → Cancellation; the server runs until the paid term ends, so back up before you cancel.
